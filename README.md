🚀 Installation & Déploiement

Déploiement sur GitHub Pages

Placez les fichiers index.html et README.md à la racine de votre dépôt :

https://github.com/aster-info/GESTION_RISQUES

Allez dans les Settings (Paramètres) de votre dépôt GitHub.

Dans la section Pages (menu latéral) :

Source : Sélectionnez Deploy from a branch.

Branch : Choisissez main (ou master) et le dossier / (root).

Cliquez sur Save.

Votre application sera disponible sous quelques minutes à l'adresse :

https://aster-info.github.io/GESTION_RISQUES/

👤 Mode Administrateur

Par défaut, l'application s'ouvre en Mode Utilisateur (accès uniquement au formulaire d'encodage).

Pour accéder au Tableau de bord :

Cliquez sur le bouton Mode Admin dans la barre de navigation.

L'onglet Tableau de bord (Admin) apparaîtra et vous donnera accès aux statistiques, au registre et à l'exportation CSV.

🛠️ Technologies Utilisées

HTML5 & JavaScript (ES6) (Architecture SPA sans framework lourd)

Tailwind CSS (Design moderne et responsive)

Chart.js (Visualisation de données et graphiques)

Lucide Icons (Iconographie)
